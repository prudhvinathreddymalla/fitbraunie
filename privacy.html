Privacy

Local-first tracking

Pulse Pantry is a static app. It has no server database, no analytics script, and no third-party tracker in this project.

Your meals, workouts, water, goals, and weekly metrics are saved in your browser's local storage on the device where you enter them.

If you publish this project on GitHub Pages, the 8-week plan files are public unless you use a private Pages-capable GitHub plan. Do not commit private health measurements or personal notes into the repository.
